# ❤️ Un Regalo Para Ti

Una experiencia web interactiva creada como un regalo digital personalizado para celebrar la culminación de un semestre especialmente desafiante.

La aplicación combina animaciones, una galaxia tridimensional interactiva, mensajes personalizados y una experiencia visual inmersiva para transmitir reconocimiento, admiración y cariño de una forma única.

---

## 🌟 Descripción

**Un Regalo Para Ti** es una aplicación web interactiva diseñada como una experiencia emocional y personalizada.

La aplicación guía al usuario a través de diferentes escenas cuidadosamente diseñadas, comenzando con una pantalla de bienvenida y culminando en un universo tridimensional donde es posible explorar distintos corazones interactivos. Cada corazón representa una cualidad especial y desbloquea un mensaje personalizado.

El proyecto fue desarrollado con un enfoque en la experiencia de usuario, las animaciones fluidas y una estética inspirada en galaxias, estrellas y elementos románticos.

---

## ✨ Características

- Pantalla de bienvenida animada.
- Transiciones suaves entre escenas.
- Universo 3D interactivo.
- Cámara orbital y navegación libre.
- Corazones tridimensionales interactivos.
- Mensajes personalizados para cada corazón.
- Animaciones de partículas.
- Fuegos artificiales.
- Confeti y efectos visuales.
- Diseño responsive para escritorio y dispositivos móviles.
- Experiencia completamente ejecutable desde navegador.

## 🚀 Instalación

Clonar el repositorio:

```bash
git clone https://github.com/USUARIO/un-regalo-para-ti.git
```

Ingresar al directorio:

```bash
cd un-regalo-para-ti
```

Instalar dependencias:

```bash
npm install
```

---

## ▶️ Ejecución Local

Iniciar el servidor de desarrollo:

```bash
npm run dev
```

Posteriormente abrir:

```text
http://localhost:5173
```

---

## 📦 Compilación para Producción

Generar la versión optimizada:

```bash
npm run build
```

Los archivos compilados se generarán en:

```text
dist/
```

## 🌐 Despliegue
